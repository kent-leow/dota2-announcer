## Key Insight

Player-mode GSI (when you're playing, not spectating) has significant limitations:
- `map.roshan_state` / `map.roshan_state_end_seconds` — NOT available (spectator-only)
- `items` — only YOUR hero's inventory
- `events[]` array — the primary source of truth for game events like roshan kills, aegis pickups

The `events[]` array is the correct mechanism for detecting these events in player mode.
