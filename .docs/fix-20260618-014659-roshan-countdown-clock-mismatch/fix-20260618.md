## Root Cause

`roshanTracker.ts` stored `roshanKillEvent.game_time` (from the events array, on `map.game_time` scale which includes pick/strategy phase offset) as `roshanKillGameTime`, but then calculated elapsed time against `state.clockTime` (from `map.clock_time`, the visible game clock starting at 0:00). The ~180s offset between these two scales inflated the countdown from the correct 8 minutes to ~11 minutes.

## Fix

Changed `roshanKillGameTime = roshanKillEvent.game_time` → `roshanKillGameTime = state.clockTime` so elapsed calculation uses the same time scale consistently.
