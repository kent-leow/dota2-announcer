## Root Cause

`gameStatusTracker.ts` mapped `respawn_extra` as a valid roshan state, but Dota 2 GSI actually sends `respawn_variable`. The type definition and mapping logic used the wrong state name, causing it to fall through to `alive` when Roshan was actually dead.

## Changes

- `gameStatusTypes.ts` — changed `'respawn_extra'` → `'respawn_variable'` in `RoshanStatus` type
- `gameStatusTracker.ts` — updated mapping to recognize `respawn_variable` instead of `respawn_extra`
- `GameStatusPanel.tsx` — updated labels: `respawn_base` = "Dead" (red), `respawn_variable` = "May respawn" (amber); countdown labels: "Until may respawn" / "Until respawn"
- `gameStatusTracker.spec.ts` — added test for `respawn_variable`, added test that `respawn_extra` (legacy) maps to `alive`
- `GameStatusPanel.spec.tsx` — updated tests to match new labels and states
