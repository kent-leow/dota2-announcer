## Root Cause

The `dev` script used `concurrently "vite" "wait-on http://localhost:5173 && electron ."` which spawns Electron manually via `electron .`. However, `vite-plugin-electron` already spawns Electron internally via its `:startup` plugin after building the main process — resulting in two Electron instances.

The manually-spawned instance (from `concurrently`) did NOT have `VITE_DEV_SERVER_URL` set in its environment (only the plugin-spawned one does), so it fell through to `loadFile()` which loaded an empty/stale `dist/renderer/index.html` — hence black screen.

## Fix Applied

- Changed `"dev"` script from `concurrently "vite" "wait-on http://localhost:5173 && electron ."` → `"vite"`
- Removed unused `concurrently` and `wait-on` devDependencies
